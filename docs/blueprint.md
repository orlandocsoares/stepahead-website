# **App Name**: Saber Mais Platform

## Core Features:

- Parallax Hero Section: Implement a full-screen parallax background using a scroll-controlled WebP frame sequence to create a cinematic effect for each phase of the program.
- Phase-Based Content Display: Display content, including phase title, subtitle, description, and CTAs, dynamically based on the current phase of the program, with smooth transitions.
- Activity Calendar: Provide a calendar-based schedule for activities like workshops and events, including dates, locations, and participation status.
- Secure Document Repository: Implement a secure repository for pedagogical documents such as manuals and presentations, with controlled access based on user roles.
- User Portfolio Management: Enable users to upload and manage their pedagogical materials and learning evidence, ensuring structured and private access.
- Role-Based User Access: Secure authentication system to allow different roles (formando, formador, administrador) with secure, role-based controlled access.

## Style Guidelines:

- Base background color: Solid light gray (#F2F2F2).
- Theme colors: Black (#000000) and white (#FFFFFF) only.
- Body and headline font: 'Inter', a grotesque-style sans-serif font. Note: currently only Google Fonts are supported.
- Sticky top navigation: Logo/program name with smooth scroll section links and active section indicator.
- Right side navigation: Large phase index number with PREV/NEXT controls, fade-in/fade-out text transitions, and background sequence swaps per phase.
- Footer: Solid black background with institutional links, monochrome social icons, and copyright notice.
- Implement smooth text transitions between content sections to provide a fluid and engaging user experience when navigating the phases and modules.
